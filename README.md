# MiniBlog

MiniBlog là ứng dụng blog xây dựng bằng React, TypeScript và Vite. Danh sách bài viết và bình luận được tải từ JSONPlaceholder; bài viết mới và trạng thái đăng nhập được lưu trong `localStorage`.

## Chạy ứng dụng

```bash
npm install
npm run dev
```

Kiểm tra TypeScript và tạo bản build production:

```bash
npm run typecheck
npm run build
```

## Tài khoản demo

- Tên đăng nhập: `admin`
- Mật khẩu: `123456`

Ứng dụng hỗ trợ tìm kiếm bài viết, xem nội dung và bình luận, đăng nhập/đăng xuất, tạo bài viết có kiểm tra dữ liệu và trang 404.
